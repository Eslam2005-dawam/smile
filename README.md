# Smile Store — storefront concept

An Arabic, right-to-left, responsive beauty-and-lifestyle storefront concept for portfolio review. The page follows the supplied blush-pink reference and includes campaign, category navigation, service benefits, best sellers, new arrivals, editorial merchandising, newsletter, and footer sections.

## Preview locally

From this directory, run:

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

The website is static HTML/CSS/JavaScript and has no package-install step. The generated, web-optimized concept images are in `assets/`.

## Prototype-only details

Product names, imagery, prices, discounts, contact details, and currency are illustrative placeholders. Search, favorites, cart count, and newsletter feedback are visual-only browser interactions; there is no connected catalog, account, mailing list, inventory, checkout, or payment processing. Update the sample content and replace the generated concept imagery with approved product photography before production.
